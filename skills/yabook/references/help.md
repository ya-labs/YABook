# Help

Use para `$yabook help`. Help nunca executa comandos, resolve workspace ou
altera estado.

## Índice geral

- contexto: `load`, `status`, `diagnose`;
- planejamento: `init`, `discuss`, `plan`;
- conversa: `steps`, `mode`;
- execução: `dev`, `do`, `apk`, `bypass`;
- GitHub: `issue`, `branch`, `commit`, `pr`, `release`;
- qualidade: `check`, `review`, `docs`;
- skill: `sync`.

Para tópico específico, carregue somente:

- planejamento: [help/plan.md](help/plan.md);
- comandos: [help/commands.md](help/commands.md);
- objetivo em linguagem natural: [help/objectives.md](help/objectives.md).

Se o tópico for desconhecido, sugira até três comandos próximos sem inventar
novos comandos.
