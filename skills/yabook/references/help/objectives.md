# Help por objetivo

Para uma intenção em linguagem natural:

1. identifique o resultado;
2. recomende o menor fluxo YABook;
3. explique cada comando;
4. diferencie análise de execução;
5. entregue a sequência pronta;
6. não a execute.

Para planejar uma versão, considere `init`, `plan start`, `plan review`, `do
plan`, `plan roadmap` e `do plan roadmap`, incluindo apenas etapas necessárias.

Para corrigir, ajustar ou melhorar algo, comece por:

```text
$yabook issue
$yabook do issue
$yabook branch name
$yabook do branch
```

Se houver caminhos reais diferentes, recomende um e informe a condição para
usar o outro.
