# Help de planejamento

Para `$yabook help plan`, apresente:

| Comando | Uso |
| --- | --- |
| `plan start <versão>` | Entrevistar e propor uma versão. |
| `discuss <tema>` | Avaliar mudança e impacto. |
| `plan status` | Mostrar maturidade e decisões abertas. |
| `plan next` | Recomendar a próxima ação. |
| `plan roadmap` | Propor milestones, épicos e próximo bloco. |
| `plan review` | Revisar coerência. |
| `do plan` | Gravar decisões aprovadas. |
| `do plan roadmap` | Criar a estrutura aprovada no GitHub. |

Comandos sem `do` não escrevem. `plan discuss` continua como alias de `discuss`.
