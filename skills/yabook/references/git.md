# Git

Carregue somente a capacidade necessária:

- inspeção somente leitura: [git/leitura.md](git/leitura.md);
- autorização e escopo de mutações: [git/mutacoes.md](git/mutacoes.md);
- avaliação do worktree antes de editar: [git/checkpoint.md](git/checkpoint.md).

Não carregue as três referências por precaução. `continue` usa o checkpoint
anterior e atualiza o estado antes de retomar.
