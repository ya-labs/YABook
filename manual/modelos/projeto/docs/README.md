# Documentação do Projeto

Este diretório guarda documentação específica e estável do projeto.

Para decidir onde registrar cada assunto, use [Guia de consulta da documentação](guia-da-documentacao.md). Ele é a fonte única da estrutura documental deste projeto.

Crie apenas documentos e pastas que fizerem sentido para o momento atual. Não crie documentação para preencher estrutura.

## Regra rápida

- Markdown guarda conhecimento estável: arquitetura, contratos, decisões, setup, uso e critérios de pronto.
- GitHub guarda trabalho executável: backlog, status, responsáveis, Project, milestones, issues e Pull Requests.
- Documento bom ajuda alguém a executar, revisar, decidir ou continuar o trabalho.

## Referência organizacional

Este projeto segue os padrões da YA LABS documentados no YABook.

Use o YABook como referência para fluxo GitHub, padrões operacionais, uso de IA, condução de projetos e boas práticas de documentação técnica.
